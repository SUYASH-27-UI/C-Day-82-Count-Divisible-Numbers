# C Day 82 - Count Divisible Numbers

This C program counts how many entered numbers are divisible by a given divisor.

## Example

Numbers: `9, 10, 12, 7, 15`

Divisor: `3`

Output:
```text
Divisible numbers count = 3
```

## Concepts Used

- Variables
- `for` loop
- `if` statement
- Modulus operator `%`
- Increment operator `++`
- `scanf()` and `printf()`

## How It Works

The program accepts a set of numbers and a divisor from the user. It uses the modulus operator to check whether each number is divisible by the divisor. The counter increases for every divisible number.
